# テーマ分類の誤判定事故・是正記録（2026-10-25）

ユーザー報告: スポーツのサッカーW杯が文学・美術に誤表示。EP-IDが一般ユーザーにはわかりづらい。

原因: 試験用 `theme-bridge-pilot.json` のルール照合で、「文学・美術」の正規表現に一文字の「本」が入っていた。日本、日本代表、日本版DBSなどを誤検出。元のAIが保存した `main_theme` には妥当な語句が残っており、悪いのは表示用の二次分類である。

処置:
- 明白なサッカー等の誤分類18件をスポーツに振り直し。
- 文学・美術の残り208件を語句で点検し、疑わしい98件のうち97件を「分類検討中」に退避、坂本花織1件をフィギュアへ移動。
- 未整理数は2,104から2,201に変化。元の自由記述主題は不変。
- `theme-network-lite.json` を更新。
- `test1025-semantic/index.html` では題名を主表示、EP-IDは管理情報に移動、未整理件数を動的に表示。

重要な制限: これだけでは他のカテゴリの誤判定は解消したといえない。共通テーマの再設計と全件の意味品質監査が必要。今後は「本」のような単一文字や番組共通定型文でのカテゴリ分けを避け、信頼できる原本AI分類を優先し、不確実なものは暫定保留にする。GitHub保存済みだがブラウザ実機での再確認は未済。本番index.htmlは変更していない。
