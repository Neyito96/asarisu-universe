# 朝リスの田 × 朝リスの宇宙｜再生・保存構想メモ

記録日：2026-10-22
状態：構想段階／未実装。開発の承認・実装着手を意味しない。

## 基本方針

- **朝リスの田**：発見したエピソードを保存し、聴くための場所。
- **朝リスの宇宙**：番組の垣根を越えて、話題・出演者・関連記事などからエピソードを発見する場所。
- Spotifyに限定せず、利用者が利用可能な配信プラットフォームを選択できるようにする。Spotifyを排除する構想ではない。
- 同じ番組内の単純な関連付けは、宇宙の番組横断探索とは別に、朝リスの田の**番組別自動プレイリスト**として扱う。

## 保存と再生は分離する

- 保存対象は原則として独立エピソード図書館の**EP-ID**。特定サービスのURLやSpotify IDだけを保存の正本にしない。
- 「あとで聴く」、ユーザー独自のプレイリスト、テーマ検索結果の保存を想定。
- 宇宙で見つけたエピソードを、朝リスの田の保存リストへ送る導線を設ける（仮称「マイ田んぼに植える」）。
- 保存したEP-IDから、図書館の最新情報を参照し、利用可能な再生先を提示する。

## 再生方式の候補

1. 公開・利用可能な公式RSS音声URLを使ったサイト内再生と連続再生。
2. Spotify、Apple Podcasts、公式配信元などへの遷移・再生先選択。
3. 将来はテーマ別・ユーザー編集のプレイリストを連続再生。

留意事項：音声URLの存在、ブラウザーでの再生可否、配信元の利用条件をエピソード単位で確認する。音声ファイルを無断で複製・再配布しない。外部プラットフォームを横断したシームレスな連続再生は、各サービスの技術仕様・規約によるため保証しない。

## 保存方式の段階案

- **第1段階**：ブラウザー内保存（localStorageなど）、ログイン不要。データ削除・端末変更による消失リスクがあるため、エクスポート／インポートを同時提供。
- **第2段階**：共有可能なプレイリスト形式・リンク。公開範囲とURLの扱いを設計する。
- **第3段階**：任意のアカウントと端末間同期。プライバシー・認証・運用コストを検討。

保存形式の例（構想）：

```json
{
  "schemaVersion": 1,
  "name": "あとで聴く",
  "episodes": ["EP-00004", "EP-00069", "EP-00072"]
}
```

## 実装前の確認事項

- 公開図書館の音声URLの収録率・有効性・権利条件
- エピソードが削除・非公開・再配信された場合の挙動
- 番組別プレイリストの更新基準（EP-ID、番組名、公開日時）
- 保存データのバックアップ、重複排除、並び替え、公開／非公開
- サイト内再生時のモバイル端末の制限と連続再生の検証
- 朝リスの田と宇宙の連携方法

## 開発順序のたたき台

1. 番組別自動プレイリスト＋再生可否調査
2. 「あとで聴く」への保存＋エクスポート／インポート
3. 宇宙からの保存導線とテーマ別リスト
4. 任意アカウント・端末間同期
