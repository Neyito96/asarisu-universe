# 朝リスの宇宙 🌌

朝日新聞ポッドキャストのエピソードを、言葉・出演者・星群から探索する実験的な可視化サイト。

- **言葉の星雲**：タイトル中の語句を星として表示。星の面積は関連エピソード件数に比例。
- **出演者の星座**：公開図書館の出演者情報から星を表示。
- **エピソード宇宙**：エピソードを星として表示。
- 星を選択すると関連エピソードの図書館詳細ページへのリンクを表示。

## 公開サイト
GitHub Pages を `main` ブランチの `/(root)` で有効にした後、以下のURLで公開予定：

https://neyito96.github.io/asarisu-universe/

## データと開発方針
公開データは `https://neyito96.github.io/asarisunowa/library/data/` のJSONをブラウザから読み取ります。図書館の台帳・GAS・Spotifyに書き込みません。EP-IDを図書館との共通キーとして使用します。

現在の語句抽出は暫定的な正規表現で、単語の意味的な近さは表現していません。出演者の欠損・再配信表記の判定にも注意が必要です。
